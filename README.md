## 一、 核心功能与特性

### 1. 用户账户系统
- **登录/注册**：提供用户登录和注册功能。
- **数据存储**：
    - 注册账号默认**仅存储在用户设备本地**，不使用云端数据库，旨在保护隐私。
    - 如需多设备同步使用，需联系管理员将账号绑定至后台。
- **注册状态**：自2025年9月16日起，APP和站点**暂停对外开放注册**，需联系管理员申请。电脑版注册功能未暂停。
- **辅助功能**：提供“**一键清除本地存储**”功能，可彻底清除本地数据（如账号密码）。

### 2. 界面与交互
- **UI设计**：网站暂时套用了APP的登录界面UI。
- **音乐播放**：增加了背景音乐弹窗播放卡，解决了之前背景音乐无法暂停、循环播放的问题。

### 3. 其他相关程序/链接
站点还提供或链接了其他功能程序，包括：
- 跳动爱心
- 归档音乐播放器
- 图片尺寸修改
- 作者简介
- 个人文件库
- Typecho（不见桃花不见秋版博客系统）下载

## 三、 开发背景与历程（发展叙事）

> 本程序的发展带有个人的情感色彩。

1.  **起源（2023年2月）**：程序前身是一个专门记录开发者与对象美好瞬间的“**恋爱记事本**”，初期功能简单。后因分手，项目被尘封。
2.  **重生（2024年）**：
    - 2024年4月，开发者前往广州，在新的环境中经历了许多人与事。
    - 2024年6月，重新启用并彻底**重构**了该程序，将其定位从一个单纯的恋爱记录，转变为一个记录个人所有见闻与情感的“**岁月记录簿**”。
3.  **定名**：程序正式改名为“**归档-时光卷轴**”，并坚持更新至今。
