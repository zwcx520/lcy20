# lcy20 - 多功能H5 Web项目（含Typecho博客系统自建包）

## 项目介绍
`lcy20` 是一个集H5静态页面、Typecho博客系统PHP自建包于一体的开源项目，包含完整的前端样式、交互脚本、媒体资源及后端核心代码，主打“不见桃花不见秋”主题风格，适用于个人博客搭建、静态网站部署等场景。项目结构清晰、资源齐全，更新活跃，支持二次开发与个性化定制。
