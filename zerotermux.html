ZeroTermux 下载教程

1. 工具介绍

ZeroTermux 是 Termux 的优化版本，修复了部分机型兼容性问题，支持更稳定的 Linux 环境部署，适合手机端安装 Kali 系统。

2. 下载地址

官方 GitHub 下载（推荐）：

https://github.com/zeroone2333/ZeroTermux/releases

备用下载链接：

https://f-droid.org/packages/com.termux/

下载后缀为 .apk 的安装包，根据手机架构选择对应版本（一般选择 arm64-v8a）。

3. 下载注意事项

① 若 GitHub 下载缓慢，可使用加速器或备用链接

② 确保手机剩余存储空间 ≥ 2GB（安装包 + 系统镜像）

ZeroTermux 安装与初始化配置

1. 安装步骤

① 下载完成后，点击 .apk 文件开始安装

② 若弹出「安装未知应用」提示，前往手机设置 → 安全 → 开启「允许安装未知来源应用」

③ 等待安装完成，点击「打开」启动 ZeroTermux

2. 权限授予

首次启动会请求存储权限，点击「允许」，否则无法下载 Kali 镜像。

手动授予权限（若未弹出请求）：

手机设置 → 应用 → ZeroTermux → 权限 → 存储 → 允许

3. 初始化配置

启动后等待自动初始化，出现命令行提示符 $ 即完成初始化。

执行命令更新软件源：

pkg update && pkg upgrade -y

ZeroTermux 部署 Kali Linux 系统

1. 安装必要依赖

在 ZeroTermux 中执行以下命令安装依赖工具：

pkg install wget proot tar -y

2. 下载 Kali 镜像脚本

执行命令下载一键安装脚本：

wget https://raw.githubusercontent.com/EXALAB/AnLinux-Resources/master/Scripts/Installer/Kali/kali.sh

3. 运行安装脚本

给脚本添加执行权限并运行：

chmod +x kali.sh
./kali.sh

等待镜像下载和安装，过程可能需要 10-30 分钟（取决于网络速度）。

4. 启动 Kali 系统

安装完成后，执行命令启动 Kali：

./start-kali.sh

出现 root@localhost:~# 提示符即表示 Kali 启动成功！

5. 初始化 Kali 配置

首次启动 Kali 后，更新软件源：

apt update && apt upgrade -y

安装常用工具（可选）：

apt install nmap sqlmap -y

常见问题与注意事项

1. 安装脚本运行失败

解决方案：检查网络连接，切换加速器；重新下载脚本，执行 chmod +x kali.sh 赋予权限。

2. Kali 启动卡顿/闪退

解决方案：关闭手机后台多余应用；确保手机内存 ≥ 4GB；重新执行 ./start-kali.sh。

3. 无法访问存储

解决方案：重新授予存储权限；在 ZeroTermux 中执行 termux-setup-storage 挂载存储。

4. 安全注意事项

① 仅用于合法的学习和测试，请勿用于未经授权的渗透测试

② Kali 镜像较大，建议在 Wi-Fi 环境下下载
